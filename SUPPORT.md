# Support

GPForum is an early-stage open-source project in active development. Support
happens in the open, on GitHub.

- **Bugs, feature requests, and architecture proposals:** open an
  [issue](https://github.com/gpicchiarelli/GPForum/issues/new/choose) using
  the matching template.
- **Security reports:** use
  [GitHub Security Advisories](https://github.com/gpicchiarelli/GPForum/security/advisories/new),
  never a public issue. See [SECURITY.md](SECURITY.md).

Before asking for help, include:

- the command you ran;
- the exact failure output;
- your OS and Perl version;
- whether `carton check`, `script/perlcritic`, and `script/test` pass.
