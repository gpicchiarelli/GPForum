# Support

GPForum is currently an early-stage private project.

Use GitHub issues for reproducible bugs, scoped feature requests, and
architecture decision proposals. Use GitHub Security Advisories for private
security reports.

Before asking for help, include:

- the command you ran;
- the exact failure output;
- your OS and Perl version;
- whether `carton check`, `script/perlcritic`, and `script/test` pass.
