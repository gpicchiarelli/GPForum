# I18N

`GPForum::Service::I18N` owns locale negotiation, catalogs, pluralization,
locale metadata, and date/time/number formatting helpers.

Supported foundation locales:

- `en`;
- `it`.

Locale resolution order:

1. authenticated session preference;
2. guest locale cookie;
3. `Accept-Language`;
4. configured default locale;
5. safe fallback to `en`.

Templates use `t()`, `l()`, `tc()`, `ui_label()`, and formatting helpers such as
`ui_date`, `ui_time`, `ui_datetime`, and `ui_number`. User-generated content,
slugs, and canonical database values are not translated. Canonical values are
translated only at the presentation layer.

`t/64-i18n.t` checks catalog coverage, missing-key behavior, fallback logging,
namespace discipline, Accept-Language negotiation, and localized SSR shell
rendering. New template-visible strings should be added to both English and
Italian catalogs before the template uses them.
