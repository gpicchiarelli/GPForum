# GPForum Visual Identity Source

This directory contains editable source artwork for the GPForum logo system.

## Files

* `gpforum-logo-source.svg` is the canonical editable source file.
* `../img/gpforum-mark.svg` is the compact exported mark.
* `../img/gpforum-logo.svg` is the horizontal exported logo.

## Editing

Open `gpforum-logo-source.svg` in Inkscape, Illustrator, Figma, Sketch, or
another vector editor that supports SVG.

The source file is organized into named groups:

* `palette`
* `mark-background`
* `network-map`
* `infrastructure-rails`
* `conversation-ribbon`
* `wordmark`

The exported assets should preserve the same theme as the hero image:

* independent operations room;
* global discussion network;
* durable infrastructure;
* warm governance and human community signals.

## Export Targets

Recommended exports:

* mark: `assets/img/gpforum-mark.svg`
* logo: `assets/img/gpforum-logo.svg`
