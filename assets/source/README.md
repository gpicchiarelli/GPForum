# GPForum Visual Identity Source

The identity is a symbol without visible text: two opposing open circular
arcs and a single amber node. The open space suggests dialogue and the node
recalls the warm connections in the hero image.

## Files

- `gpforum-logo-source.svg`: editable master with champagne arcs and an amber node.
- `../img/gpforum-logo.svg`: charcoal version for light backgrounds.
- `../img/gpforum-logo-dark.svg`: champagne version for dark backgrounds.
- `../img/gpforum-mark.svg`: compact symbol that follows the device color scheme.
- `../img/gpforum-symbol-v2.svg`: original approved symbol.

The master and logo variants use a square 128 × 128 viewBox. The compact
mark uses a tighter 96 × 96 viewBox for legibility at favicon sizes. All
assets use a transparent background, solid colors, and geometric paths. There is no wordmark or tagline. The accessible
name is metadata and is not displayed. Edit the master in a vector editor
and keep the arc geometry and spacing consistent across exports.
