Platform

Built for communities that outlive trends.

GPForum treats a forum as civic software: conversations, policy, moderation, search, events, and operations are all first-class parts of the system.

Durable discussion

Spaces, categories, threads, posts, revisions, archival, and search are modeled as long-lived community assets.

Operational moderation

Reports, scoped staff authority, reversible actions, audit logs, and policy versioning keep governance visible.

Independent stack

Modern Perl, Mojolicious, DBIx::Class, PostgreSQL full-text search, Minion, and a Redis-optional coordination model.

Architecture

A modular monolith with distributed instincts.

The design favors explicit boundaries, stateless app nodes, event tables, asynchronous projections, observable workers, and cache layers that can be rebuilt.

Edge Nginx or HAProxy
Application Mojolicious nodes
Domain Identity, discussion, moderation, authorization
Persistence PostgreSQL, event log, audit log
Derived systems Minion, PostgreSQL FTS, local caches, realtime
Governance

The rules are part of the product.

GPForum does not bury moderation inside ad hoc admin screens. Policy, trust, role scope, auditability, appeals, content lifecycle, and privacy rights are documented as architecture.

01

Deny by default

Authorization evaluates actor, action, target, scope, resource state, and user state.

02

Events tell the truth

Durable domain events drive projections, notifications, replay, and audit investigation.

03

Privacy is operational

Retention, deletion, export, consent, search visibility, and breach readiness are explicit.

Roadmap

From constitution to running system.

The repo now has enough architecture to start implementation without turning the first codebase into guesswork.

  1. Milestone 0 Project skeleton

    Mojolicious app, DBIx::Class schema shell, migrations, logging, health, tests, and Perl::Critic.

  2. Milestone 1 Identity

    Registration, login, logout, sessions, revocation, CSRF, and account status checks.

  3. Milestone 2 Core forum

    Spaces, categories, threads, posts, revisions, pagination, and safe server-rendered composition.

  4. Milestone 3 Moderation

    RBAC, ABAC ownership checks, reports, scoped staff authority, hidden content, and audit trails.
